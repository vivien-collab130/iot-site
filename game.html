    // WHAT I LEARNED BUILDING THIS

    Everything I learned in this workshop, and where it shows up in this game.

    📬 Feeds
    A feed is a mailbox in the cloud. The game feed carries every round and score.
    🛎️ Arduino → Website
    My Doorbell project sent button presses to a website. Here, the Arduino sends scores.
    💡 Website → Arduino
    My Remote Lamp project let a phone change real lights and play music.
    🔁 Polling vs. Subscribing
    This screen polls: it checks every 2 seconds. My Lamp subscribed: messages were pushed to it.
    🚦 Rate Limits
    Adafruit IO allows 30 messages a minute, so the Arduino waits 2 seconds between messages.
    🔐 Keeping Secrets Safe
    My key is never in the code or on GitHub. It stays in a secrets file on my computer.
    🌐 Publishing a Website
    This page is live on the internet with GitHub Pages, so anyone with the link can see it.
    🐞 Debugging
    If something breaks, I check the feed: if the message is there, the bug is in the website. If not, it's in the Arduino.
