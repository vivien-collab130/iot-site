    // WHY IS THIS SO HARD TO STOP PLAYING?

    This game uses real psychology. See if you noticed these while you played!

    😩 The near-miss effect: losing by just a little makes your brain want to try again even more than winning. Slot machines use this on purpose.
    🎯 A goal you can see: the progress bar shows exactly how close you are to the record, so you try harder.
    🏅 Status: ranks like "Brain Beast" give you something to be proud of, and a next rank to chase.
    👥 Social comparison: other groups are watching, and everyone wants to beat them.
    📈 Rising tension: the screen heats up as you get closer to the record, and so does your heart rate.
    🎉 Big rewards: when a group takes the crown, everyone watching wants that moment too.

    // DID YOU KNOW?

    The brain science behind the colors and sounds.

    Synesthesia is when one sense triggers another. Some people see colors when they hear music. In a room this size, someone here might have it!
    Seeing + hearing = better memory. Each pattern is shown as a color and a note at the same time, so your brain stores it twice. That's why you can often "hum" the pattern back.
    Most people can hold only about 4 to 7 things in their head at once. That's why scores usually get stuck around rounds 5 to 8. Try grouping the notes into little tunes to go further!

    // WHAT I LEARNED BUILDING THIS

    Everything I learned in this workshop, and where it shows up in this game.

    📬 Feeds
    A feed is a mailbox in the cloud. The game feed carries every round and score.
    🛎️ Arduino → Website
    My Doorbell project sent button presses to a website. Here, the Arduino sends scores.
    💡 Website → Arduino
    My Remote Lamp project let a phone change real lights and play music.
    🔁 Polling vs. Subscribing
    This screen polls: it checks every 2 seconds. My Lamp subscribed: messages were pushed to it.
    🚦 Rate Limits
    Adafruit IO allows 30 messages a minute, so the Arduino waits 2 seconds between messages.
    🔐 Keeping Secrets Safe
    My key is never in the code or on GitHub. It stays in a secrets file on my computer.
    🌐 Publishing a Website
    This page is live on the internet with GitHub Pages, so anyone with the link can see it.
    🐞 Debugging
    If something breaks, I check the feed: if the message is there, the bug is in the website. If not, it's in the Arduino.
